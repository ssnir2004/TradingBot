Remote Worker
A worker token lets a script running on your own computer (backtest_worker.py) poll this dashboard for backtests marked "Run on remote worker" above, compute them locally, and report the result back — freeing this server from the CPU/memory cost of running them itself. See docs/worker.md for full setup. The raw token is shown only once, right after you generate it — store it somewhere safe (e.g. your worker's local .env file); it can't be retrieved again afterward.
